Guides

A little guidance for the newcomers.

💬

Joining the Discord

  1. Click the Join the Discord button on the home page.
  2. If the link is expired, please send a feedback.
  3. Read #rules first.
  4. Say hi in #chat.
🐛

Reporting a Bug

  1. Go to the Feedback page.
  2. Title it anything, select Bug Report.
  3. Desc: Where, What, How.
  4. Screenshots or recordings help a lot.
💡

Suggesting an Idea

  1. Search existing one first.
  2. Title it anything, select Suggestion.
  3. Explain why and how it could work.
  4. Keep it to one clear idea per post.
📈

Game Progress

Track how the game itself is coming along.

  1. See the Progress page.
